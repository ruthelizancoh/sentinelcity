# SentinelCity

A portfolio of five small, complete Python programs, each simulating a
real decision-making system used by a real kind of organization -- a
cybersecurity team, an airport, a bank, an antivirus company, and an
account security team.

Each project lives in its own numbered folder, with its own detailed
README and its own runnable Python file. Every project uses only
comparison operators, `if` / `elif` / `else` conditionals, and boolean
logic (`and`, `or`, `not`).
